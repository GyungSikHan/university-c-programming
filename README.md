## C언어 기초 · 2016년 2학기

입력값에 따라 프로그램의 흐름을 제어하고, 반복 계산 결과를 배열에 저장·출력하는 실습을 진행했습니다.

### 1. 입력값에 따른 도형 출력

[소스 코드](2016-2-c-basics/2016225167%20%281%29.c)

- 양의 정수가 짝수이면 정사각형, 홀수이면 십자 모양을 출력합니다.
- 중첩 반복문으로 행과 열을 순회합니다.
- `x == a / 2 || y == a / 2` 조건으로 중앙 행과 열을 판별합니다.

입력 `5`에 대한 예상 출력(코드 분석 기준):

```text
  *
  *
*****
  *
  *
```

### 2. 함수 계산 결과의 배열 저장·합산

[소스 코드](2016-2-c-basics/2016102.c)

- `2x + 7`과 `4x² - 2x + 3`을 각각 함수로 작성했습니다.
- `-10`부터 `10`까지 두 함수의 차이를 계산해 21칸 배열에 저장했습니다.
- `x + 10`으로 음수를 포함한 입력 범위를 배열 인덱스 0~20에 대응시켰습니다.
- 저장한 값들을 출력하고 합계를 계산했습니다.

### 3. 1차원 배열을 이용한 격자 표현

[소스 코드](2016-2-c-basics/20161128.cpp)

- 49칸 배열에 0~48을 저장하고 7×7 격자 형태로 출력했습니다.
- `y * 7 + x`로 행·열 좌표를 1차원 배열 인덱스로 변환했습니다.
- 나머지 연산으로 짝수 원소만 출력하도록 분기했습니다.
- 확장자는 `.cpp`이며, 구현은 C 스타일입니다.

## C언어 고급 · 2017년 1학기

### 1. 계산기와 연산 라이브러리 분리

| 구성 | 역할 |
| --- | --- |
| [Calculator/Calcu.c](2017-1-c-advanced/Calculator/Calcu.c) | 두 정수 입력, 연산 함수 호출, 결과 출력 |
| [MyLibrary/MyHeader.h](2017-1-c-advanced/MyLibrary/MyHeader.h) | 연산 함수 선언 |
| [MyLibrary/MyLib.c](2017-1-c-advanced/MyLibrary/MyLib.c) | 연산 함수 구현 |

입출력을 담당하는 프로그램과 계산 기능을 나누어 작성했습니다. 사칙연산을 함수로 구현하고 거듭제곱, 두 수의 차에 대한 팩토리얼 연산을 추가하는 실습을 진행했습니다. Calculator의 Debug 프로젝트 설정에는 `MyLibrary.lib`를 연결하는 구성이 남아 있습니다.

이를 통해 헤더의 선언, 소스의 구현, 라이브러리를 사용하는 호출 코드 사이의 관계를 학습했습니다.

### 2. 명령행 인자와 파일 기록

[소스 코드](2017-1-c-advanced/MyLog/MyLog.c)

- `argv[1]`과 `argv[3]`을 `atoi`로 정수로 변환했습니다.
- 두 값의 대소 관계를 비교해 `>`, `<`, `==` 중 하나를 결정했습니다.
- `fopen`, `fprintf`, `fclose`로 비교 결과를 `log.txt`에 기록했습니다.
- 파일 열기 실패 시 종료하고, 사용법을 출력하는 함수를 별도로 작성했습니다.

중간 인자인 `argv[2]`는 연산에 사용하지 않습니다. 파일은 `w` 모드로 열기 때문에 실행 시 기존 내용을 덮어쓰는 구조입니다.

## 원본 코드와 실행 환경

수업 당시 소스를 보관한 학습 기록입니다. 이번 정리에서는 원본 코드를 수정하지 않았으며, 현재 환경에서 빌드·실행 검증은 하지 않았습니다.

- 기초 실습은 파일별로 독립적인 프로그램입니다. 실행할 소스 하나를 선택해야 하며, 전체가 주석인 파일도 있습니다.
- 고급 실습에는 Visual C++ 6.0 형식의 `.dsw`·`.dsp` 프로젝트 파일이 포함되어 있습니다.
- 일부 코드는 `conio.h`, `windows.h`, `getch`, Windows 콘솔 API를 사용합니다.
- 한글 문자열과 주석은 CP949 인코딩을 기준으로 확인했습니다.
- 현대 컴파일러에서 실행하려면 `void main` 등 비표준 작성 방식과 프로젝트 설정을 점검해야 합니다.
