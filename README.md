# University C/C++ Programming

C언어 기초·고급 수업 자료와 관련 C/C++ 학습 코드를 모은 저장소입니다. 콘솔 입출력과 제어문부터 포인터, 함수 분리, 파일 출력, 클래스·상속, 자료구조와 알고리즘까지 학습 내용을 정리했습니다.

폴더는 `2016-2-c-basics`와 `2017-1-c-advanced`로 구분되어 있습니다. 추가된 연습 코드와 풀이 모음도 포함하므로, 폴더명이 모든 파일의 작성 시기나 수업 출처를 의미하지는 않습니다.

## C언어 기초 실습

## C 언어 고급 실습 및 C++ 확장 학습

### 1. 계산기와 연산 라이브러리

[Calcu.c](2017-1-c-advanced/Calculator/Calcu.c)는 입력과 결과 출력을, [MyLib.c](2017-1-c-advanced/MyLibrary/MyLib.c)는 연산을 담당합니다. [MyHeader.h](2017-1-c-advanced/MyLibrary/MyHeader.h)에 함수 선언을 모아 호출 코드와 구현을 분리했습니다.

사칙연산을 함수로 작성하고 거듭제곱과 두 수의 차에 대한 팩토리얼 계산을 추가하는 연습을 진행했습니다. 기존 Calculator Debug 설정에는 정적 라이브러리 `MyLibrary.lib` 연결이 포함되어 있습니다.

### 2. 명령행 인자와 파일 기록

[MyLog.c](2017-1-c-advanced/MyLog/MyLog.c)에서 `argv[1]`과 `argv[3]`을 정수로 변환하고, 두 값의 대소 관계를 `log.txt`에 기록합니다. `fopen`·`fprintf`·`fclose`를 사용하고 파일 열기 실패를 처리합니다. 가운데 인자는 계산에 사용하지 않으며, 파일은 `w` 모드로 열어 기존 내용을 덮어씁니다.

### 3. 클래스와 상속

[class 폴더](2017-1-c-advanced/class/)에는 동물의 나이·무게·키를 공통 `Animal` 클래스로 묶고 `PIG`·`COW`·`DOG`가 상속하는 예제가 있습니다. 기본 생성자와 매개변수 생성자, `private`·`protected` 접근 제어를 학습한 기록입니다.

### 4. 단일 연결 리스트

[game.cpp](2017-1-c-advanced/6_ConsoleApplication5.cpp/game.cpp)와 [game.h](2017-1-c-advanced/6_ConsoleApplication5.cpp/game.h)에서 값과 다음 노드 포인터를 가진 구조체를 정의합니다. `add`는 리스트 끝을 찾아 새 노드를 연결하고, `print`는 시작 노드부터 순회해 값을 출력합니다. 파일명에 game이 있지만 내용은 연결 리스트 실습입니다.

### 5. STL과 격자 변환

[02 STL Summary](2017-1-c-advanced/02%20STL%20Summary/)에는 vector와 사용자 정의 비교 함수를 사용하는 정렬, 문자열 처리, 격자 탐색·변환 풀이가 있습니다.

대표 예제인 [16.cpp](2017-1-c-advanced/02%20STL%20Summary/16.cpp)는 N×N 배열을 복사한 뒤 `map[i][n - j - 1] = temp[j][i]`로 좌표를 변환해 시계 방향으로 90도 회전합니다. 입력·회전·출력 함수를 나누고 지정 횟수만큼 반복합니다.

### 6. 자료구조 설계 문제 풀이

MinStack, 배열 섞기, RandomizedSet, 2차원 벡터 순회, 틱택토와 이진 트리 직렬화·역직렬화 문제를 다룬 풀이가 포함되어 있습니다. 경계 조건과 초기화가 미완성인 코드도 있으므로, 완성된 범용 라이브러리나 모든 테스트를 통과한 풀이로 분류하지 않습니다.

## 코드 열기와 실행

- 전체 저장소는 하나의 실행 프로그램이 아닙니다. 실행할 예제와 필요한 소스 파일만 선택해 프로젝트를 구성해야 합니다.
- `포인터배열문제.c`, `배열문제.c` 등은 코드 조각이므로 필요한 헤더와 `main` 안에 넣어 실행해야 합니다.
- 주석으로 묶인 풀이, 여러 `main`이 들어 있는 파일, 설명과 출력 결과를 함께 적은 기록도 있습니다. 필요한 예제를 분리해서 사용하세요.
- Calculator·MyLibrary·MyLog에는 Visual C++ 6.0 형식의 프로젝트가 있으며, 다른 폴더에는 이후 버전의 Visual Studio 프로젝트와 독립 소스가 혼재합니다.
- `conio.h`·`windows.h`를 사용하는 코드는 Windows 환경에 의존합니다. 소스 인코딩도 CP949와 UTF-8이 혼재합니다.
- `.gitignore`는 빌드 결과와 IDE 캐시를 제외합니다. 필요한 실행 파일과 정적 라이브러리는 소스에서 다시 빌드해야 합니다.
